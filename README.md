# 정세일 | Career Folio

영상·CG 교육, 교육과정 개발, 학과 운영 경력을 소개하는 반응형 개인 사이트입니다.

## 내용 관리

`profile.js`의 `window.PROFILE`을 수정하면 소개, 이력서, 자기소개서, 프로젝트 상세 화면에 반영됩니다. 자기소개서는 두 이력서와 추가로 제공된 자소서·포트폴리오 정리 자료를 함께 반영하여 다섯 주제로 편집했습니다. 원본의 조언·편집 메모는 공개 문장에서 제외했습니다.

- 경력 및 프로젝트 기간은 두 이력서의 기재 내용을 따릅니다. 총 경력은 지존포스트프로덕션 경력까지 포함한 두 번째 이력서의 5년 7개월을 사용합니다. 두 회사의 전환 월(2021.04)을 중복 합산하지 않습니다.
- 교육혁신위 프로젝트는 학과장 경력과 겹치는 참여 이력이며 경력 기간에 중복 합산하지 않습니다.
- 첫 이력서에서 비공개 처리된 회사명은 두 번째 이력서의 SBS아카데미컴퓨터아트학원 구월로 확인했습니다.
- 실제 영상·이미지 결과물과 외부 프로젝트 링크는 추가할 수 있습니다.
- 공개 연락처는 이메일과 희망 근무 지역으로 구성했습니다.
- 상세 집주소, 전화번호, 구직인증번호, 원본 PDF는 저장소에 포함하지 않습니다.

## 실행 및 배포

빌드 과정 없이 GitHub Pages의 main 브랜치 루트에서 배포합니다.
로컬 실행: `python -m http.server 8017 --bind 127.0.0.1`

이력서 화면의 ‘인쇄 / PDF 저장’은 브라우저 인쇄 기능을 사용합니다.


## 모션그래픽 갤러리

학원 공개 갤러리의 영상/모션2D 및 영상/모션3D 전체를 `motion-gallery-data.js`에 보존합니다. 작품은 수강생 제작 / 교육·지도 포트폴리오로 표시하며 원본 제목, 영상 URL, BEST 표시, 제공된 제작자 정보를 유지합니다. 개인 제작 경력과는 별도 영역으로 구성합니다.

데이터 갱신: `python sync-motion-gallery.py` 실행 후 변경 내용을 커밋·배포합니다. 이 스크립트는 원본 데이터베이스를 읽기만 하며 수정하지 않습니다. 영상은 YouTube 원본을 임베드하며, 재생 제한에 대비해 원본 시청 링크를 제공합니다. 갤러리는 배포 시점의 스냅샷입니다.

## 전체 구성

- 소개: 제작 → 피드백·디렉팅 → 학과 운영 → 교육혁신위 → AI 활용의 경력 확장
- 이력서: 정확한 재직 기간, 제작·디렉팅·관리·AI 역량
- 자기소개서: 경력 소개 / 영상 제작 경험 / 프로젝트·조직 기여 / AI 제작 환경 / 지원 방향
- 포트폴리오: 개인 제작 → 조직 프로젝트 → AI 제작 과정 → 지원 방향 → 학생 작품 111개
- 개인 프로젝트에는 확인된 업무 이력을 표시하며, 실제 대표작 영상·이미지와 프로그램명은 별도 자료가 있을 때 추가합니다.
