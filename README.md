# 정세일 | Career Folio

영상·2D·3D 모션그래픽 제작에서 디렉팅, 프로젝트 운영, 생성형 AI 활용으로 확장한 경력을 소개합니다.

**MAKE / DIRECT / LEAD / ADAPT**

## 구성

- 소개: 제작의 전 과정을 보는 영상 제작자로서의 경력과 강점
- 이력서: 재직 기간, 영상 제작·디렉팅·조직 관리·콘텐츠 기획의 구체적 역할
- 보유 역량: 제작, 비주얼 디렉팅, 기획, 프로젝트 관리, 커뮤니케이션, AI 활용
- 사용 프로그램: After Effects, Premiere Pro, Cinema 4D, Photoshop, Blender, AI
- 자기소개서: 경력 / 제작 / 프로젝트·조직 기여 / AI / 지원 방향의 다섯 챕터
- 개인 프로젝트: CG Production / Brand & Promotion / Education Innovation / AI × Video / Creative Direction & Review
- 교육·디렉팅 작품: 대표 8개와 별도 전체 아카이브 111개(2D 59개, 3D 52개)

## 내용 수정 및 정적 HTML 생성

`profile.js`에 경력·문안·프로그램·프로젝트 데이터를 관리합니다. 사용자가 제공한 두 이력서, 자소서·포트폴리오 PDF, 최종 수정 문안을 함께 반영했습니다.

총 경력 5년 7개월과 SBS아카데미 재직 5년 3개월을 구분합니다. 교육혁신위원 활동은 재직 중 참여 이력이며 경력에 중복 합산하지 않습니다.

홈페이지 내용 변경 후 아래 명령으로 실제 소개 문구를 HTML에도 반영합니다. JavaScript 실행 전이나 검색 크롤러에서도 같은 소개 내용이 표시됩니다.

```sh
node build-static.cjs
```

미리보기: `python -m http.server 8017 --bind 127.0.0.1`

GitHub Pages는 main 브랜치 루트에서 배포합니다. `#resume`, `#story`, `#work`, `#archive`로 각 화면에 접근할 수 있습니다. 이력서의 인쇄 버튼은 브라우저 인쇄와 PDF 저장을 지원합니다.

## 작품 아카이브

`motion-gallery-data.js`는 원본 공개 갤러리의 2D·3D 모션그래픽 데이터를 보존합니다. 대표작은 원본 BEST 표시를 우선해 2D·3D 각 4개를 선정합니다. 학생이 제작한 작품이며 정세일의 교육·피드백·디렉팅 참여 결과물로 표시합니다. 원본 제목과 영상 속 제작자 표기를 유지합니다.

`python sync-motion-gallery.py`로 데이터 스냅샷을 갱신한 후 커밋·배포할 수 있습니다. 이 스크립트는 원본 데이터베이스를 읽기만 하며 변경하지 않습니다. 원본 학원 갤러리로 연결하는 링크는 공개 화면에 표시하지 않습니다.

개인 프로젝트의 실제 영상·이미지와 외부 결과물 링크는 제공된 자료에 맞춰 추가할 수 있습니다. 학생 작품을 개인 제작물로 표기하지 않습니다.

공개 연락처는 이메일과 희망 근무 지역으로 구성했습니다. 상세 집주소, 전화번호, 구직인증번호, 원본 PDF는 저장소에 포함하지 않습니다.
